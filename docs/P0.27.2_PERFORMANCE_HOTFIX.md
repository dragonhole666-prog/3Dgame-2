# P0.27.2 Performance Hotfix

Local P0.27.1 source review found several concrete client-side performance issues.

## Verified hot spots

1. The server sends snapshots at 10 Hz.
2. P0.27.1 calls `Character.setEquipment()` on every received snapshot.
3. `setEquipment()` rebuilt equipment and started fresh GLB imports even when slot/baseId visuals had not changed.
4. The spawn area creates three NPC characters immediately, and the former NPC policy reused the 18 MB / high-primitive Qinglan hero VRM for every NPC.
5. Current cascaded-shadow casters are static world meshes, but the shadow map was refreshed every frame.
6. Render diagnostics scanned active meshes and triangle indices every frame.
7. High detail forced primary world meshes to `alwaysSelectAsActiveMesh=true`.

## P0.27.2 local hotfix

- stable visual-equipment signature; unchanged equipment no longer rebuilds/reimports
- customization signature; unchanged customization no longer reapplies
- lighter base VRMs for NPCs while keeping their equipment/outfit identity
- static cascaded shadow refresh only after caster/settings changes
- render stats sampled every 0.5 s
- high detail keeps normal Babylon frustum culling
- collision membership uses a Set

The reference LookDev remains Babylon-native: PBR, ACES, SSAO where enabled, bloom, atmosphere and the custom reference grade.
