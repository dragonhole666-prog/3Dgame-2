# P0.27.1 Babylon.js-Only Migration Status

## Engine policy

P0.27.1 is a single-engine runtime. The former Three.js runtime has been physically removed from the project source. Active client, editor, character, monster, world and server-navigation code must not import or depend on Three.js.

Babylon.js is the only browser 3D renderer:

- @babylonjs/core 9.28.0
- @babylonjs/loaders 9.28.0
- @babylonjs/materials 9.28.0

The dependency graph no longer includes three, @pixiv/three-vrm, three-vrm or three-pathfinding.

## Removed

- src/legacy-three/
- legacy Three.js regression tests
- R13-R16 Three.js verification scripts
- stale P0.26 / HF / R-series renderer notes
- old runtime cache output
- legacy tsconfig/vitest exclusions

## Babylon-native replacements

- Babylon character GLB/VRM loading
- AnimationGroup-based locomotion/combat state runtime
- Babylon skeletal equipment binding
- Babylon MorphTarget expression runtime
- Babylon world renderer
- Babylon monster/Boss renderer with skeleton-first scale calibration
- renderer-independent server A* navigation

## LookDev / rendering

The commercial xianxia LookDev remains Babylon-native: semantic PBR materials, warm key/cool fill lighting, cascaded shadows, SSAO2, ACES tone mapping, restrained bloom, localized atmosphere and a reference-matched cinematic grade.
