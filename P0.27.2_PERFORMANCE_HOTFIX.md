# P0.27.2 Performance Hotfix

This hotfix targets verified client-side performance architecture issues in P0.27.1.

## Fixed

1. **Equipment reload storm**
   - Server snapshots arrive at 10 Hz.
   - P0.27.1 called `Character.setEquipment()` on every snapshot.
   - `setEquipment()` rebuilt every slot and started fresh GLB imports even when visual equipment had not changed.
   - P0.27.2 adds a stable visual equipment signature and rebuilds only when slot/baseId changes.

2. **Repeated customization work**
   - Character customization is now applied only when its value changes.

3. **NPC asset cost**
   - Three NPCs no longer each load another copy of the 18 MB / 81-primitive Qinglan hero VRM at spawn.
   - NPCs use the lighter base male/female VRMs while preserving their outfit/equipment identity.

4. **Static cascaded shadow cost**
   - Current shadow casters are static world meshes.
   - Their cascaded shadow map now refreshes once after caster/settings changes instead of every rendered frame.

5. **Production telemetry**
   - Active-mesh triangle/draw-call diagnostics are sampled twice per second rather than scanning active meshes every frame.

6. **Frustum culling**
   - High model detail no longer marks all primary world meshes as `alwaysSelectAsActiveMesh`.

7. **Camera collision predicate**
   - Collision membership changed from array `.includes()` to a Set lookup.

## Still intentionally enabled

The reference LookDev remains intact: Babylon PBR, ACES, restrained bloom, SSAO where allowed, atmosphere and reference grade.
