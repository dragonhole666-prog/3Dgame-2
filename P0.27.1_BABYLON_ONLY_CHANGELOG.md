# P0.27.1 Babylon.js Only

P0.27.1 removes the former Three.js runtime instead of quarantining it.

Key changes:

- deleted legacy Three.js source, tests and verification scripts
- removed Three.js-family dependencies from package.json
- implemented Babylon-native character animation, equipment and facial-expression runtimes
- moved curated equipment data to engine-independent metadata
- fixed equipment parallel-load cancellation by using per-slot load tokens
- fixed authored equipment GLB loading so real curated assets are used
- retained Babylon-native world, monster/Boss and commercial LookDev systems
- made server navigation renderer-independent
- added strict Babylon-only repository verification and CI release gate

The branch remains draft until complete source/LFS import and network-backed typecheck/test/build succeed.
